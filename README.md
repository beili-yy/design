# BSP 小程序 UI 设计规范

宝思派（BSP）智能家居微信小程序的 UI 设计规范文档，涵盖色彩、字体、圆角、图标、布局等设计系统定义。

## 文档内容

本仓库包含完整的 UI 设计规范 Markdown 文档（`宝思派小程序 UI 设计规范.md`），具体章节包括：

### 1. 色彩系统
- 品牌主色（Brand Primary）
- 功能色（Success / Warning / Error / Link）
- 中性色阶（Neutral Palette）
- 色彩使用规则与无障碍对比度要求

### 2. 字体规范
- 字体家族与回退策略
- 字号层级（H1–H6、Body、Caption）
- 字重使用规范

### 3. 圆角规范
- 圆角 Token 定义（xs / sm / md / lg / xl / full）
- 各组件对应的圆角值

### 4. 图标规范
- 图标库分类（设备多状态 / 设备单状态 / UI 基础）
- 图标尺寸与命名规范
- 完整图标清单（94 个）

### 5. 布局规范
- 栅格系统
- 间距 Token（spacing-xs ~ spacing-3xl）
- 安全区域与页面结构
